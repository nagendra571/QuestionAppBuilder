# Platform 1 — Definition and Evaluation Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make versioned definitions, visibility, scoring, and publishing reliable and testable before exposing the new respondent workflow.

**Architecture:** Retain Domain/Application/Infrastructure. Add typed definition settings and pure evaluation services; enforce draft revisions and publication transactions in SQL Server. Adapt existing editor endpoints alongside service changes so the existing host continues to work.

**Tech Stack:** Existing net8.0, ASP.NET Core MVC/Razor Class Libraries, EF Core 8, SQL Server, xUnit and FluentAssertions 7. Browser tests use Playwright .NET after dependency verification.

**Spec:** ../specs/2026-10-17-questionappbuilder-platform-design.md (approved in conversation).

**Status:** Proposed implementation plan; review and execution-method selection precede product edits.

## Global Constraints

- One organization and one SQL Server database per deployment, with many configured applications and users.
- Immutable published definitions and submissions; responses pin their definition version.
- Durable save-and-resume in the first release.
- Per-application access mode: host sign-in or account-free email-link access.
- All visible required answers are enforced at submission; navigation independence is not anonymity.
- SQL schema changes use generated EF migrations; no data reset is implied.
- Follow the shared conventions and baseline in 2026-10-17-platform-implementation.md. Exact paths containing braces expand into one file per listed name, not a literal brace filename. Migration timestamp placeholders are generated by EF tooling.
- UI and test projects must be registered in the solution in the task that creates them. Add DI registrations and required project references in the owning task, not an untracked final cleanup.

## Review Focus

- A required numeric zero must count as answered (Task E3).
- Reordering a referenced question must invalidate forward conditions (E3/E4).
- Changing options must not leave a published rule pointing outside its version (E4).
- Two administrators saving different child objects must still conflict at draft level (E4).
- Missing SQL configuration must report skipped, not passed (E1).
